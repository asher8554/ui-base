# ui-base

Yumeta Cursor UI 디자인 갤러리를 GitHub Pages에서 열 수 있도록 정적 HTML로 클론한 저장소입니다.

## Local Preview

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173/index.html`을 엽니다.
